# Rice Variety Classification using VGG-16

Official implementation of the research paper: **"Applying VGG-16 for Classification of Rice Varieties Incorporating Color and Texture Features"**.

## Overview
This repository contains the source code and experimental notebook for classifying different rice varieties by extracting and combining deep learning features from VGG-16 with traditional color and texture descriptors.

## Files
* `Rice_V_final_VGG16_(3) (1).ipynb`: Main Jupyter Notebook containing data preprocessing, feature extraction, model training, and evaluation.
